# 校园探索家 Campus Explorer

> 把深圳大学粤海校区变成一张可以探索、养成、收集的游戏地图。
「校园探索家」是一个面向深大同学的校园探索小游戏：地图上散落着 14 个真实校园点位和 3 个隐藏点位，走到点位附近（GPS 验证）即可打卡，点亮迷雾、完成任务、喂养你的校园精灵。**它想让"熟悉校园"这件事变得有趣、有陪伴感。**

> 「探索」不只是探索地理位置，更是探索校园生活——新活动、新美食、新朋友、新社团。新生用它熟悉校园，老生用它记录日常、解锁新体验。未来的社交功能（好友、组队、排行榜）也会围绕这个定位展开。，走到点位附近（GPS 验证）即可打卡，点亮迷雾、完成任务、喂养你的校园精灵。并在后续我想让它成为大家在校园内多走动，多去利用校园资源去达成自我成长的一个督促。

## ✨ 功能特性

- 🗺️ **真实校园地图**：以深圳大学粤海校区官微地图为底图，点位按真实位置标注
- 🌫️ **迷雾探索**：未打卡区域灰暗显示为"？"，打卡后图标点亮、雾圈散去
- 🕵️ **隐藏打卡点**：校园猫出没点、宵夜街、天台夕阳——达成条件才会在地图上浮现
- 🥚 **宠物养成**：8 个成长阶段（蛋 → 孵化 → 幼年 → … → 校园守护兽）
- 🎭 **动态性格**：宠物性格由你的打卡类型决定（学习→学霸型、运动→运动型…）
- 🎯 **今日任务**：每天 0 点自动刷新 3 个任务，用日期做随机种子
- 🏅 **成就徽章**：随探索进度解锁
- 👤 **我的主页**：宠物自动介绍 + 自定义简介
- 📍 **GPS 定位验证**：Haversine 公式计算距离，真实到达才能打卡

🎨 游戏设计思路
1. 核心循环
看地图 → 接任务 → 实地打卡 → 点亮迷雾 → 喂养宠物 → 解锁新内容

2. 隐藏点的两种解锁机制
累计解锁：完成 N 个任务后浮现（如校园猫出没点、天台夕阳）
地点解锁：完成某个指定地点的全部任务后浮现（如"完成小西门的任务 → 解锁宵夜街"）
这样设计是因为宵夜街有空间上的前置逻辑——你确实要从小西门出去才能发现它，比单纯的数字阈值更符合直觉。

3. 宠物属性"动态重算"
宠物属性不单独存储，而是每次从"已完成任务列表"实时重算：

学习系打卡 → 智力；运动系 → 体力；美食系 → 饱食；探索系 → 好奇；生活/隐藏系 → 幸运

这样做的好处是：永远不会有"属性对不上"的 bug，老进度也会自动同步到新版本。

4. 今日任务"无后端"实现
每天 0 点刷新任务，但纯前端没有服务器。解决方案：用日期字符串做随机种子（mulberry32 伪随机算法），保证同一天任何设备算出的 3 个任务完全相同，过了 0 点自然更换。

🔧 如何定制
修改点位/任务：编辑 data.js
x / y：点位在地图上的百分比坐标（0~100）
lat / lng：真实 GPS 坐标（WGS-84）
radius：打卡允许半径（米）
category：系列（study/sports/food/life/explore/hidden）
hidden: true：隐藏点；unlockAt 或 unlockAfterSpot：解锁条件
采集 GPS 坐标：手机打开 index.html?debug，右下角点"获取当前坐标"
换地图：替换 map.png，再调整各点位的 x/y
📝 开发日志（踩坑与解决）
以下是我开发过程中真实遇到的问题：

自绘 SVG 地图对不上真实布局 → 放弃自绘，改用深大官微地图做底图，点位用百分比坐标叠加上去，既真实又省时。
隐藏点解锁 bug：宵夜街没有 unlockAt，旧代码 s.unlockAt || 0 导致任意任务都能解锁它 → 重构解锁函数，区分"累计解锁"和"地点解锁"两种模式，并清理 localStorage 残留状态。
电脑定位偏差几百米：台式机无 GPS 芯片，靠 IP 定位 → 添加"演示模式"开关，测试时跳过定位；真实定位只用于手机场景。
坐标系偏差：百度/高德地图坐标与手机 GPS（WGS-84）有偏移 → 采用 iPhone 指南针直接采集 WGS-84 坐标，并适当放大打卡半径。
手机浏览器禁定位：HTTP 地址下 geolocation 不可用 → 部署到 GitHub Pages（HTTPS）或使用 localhost。
